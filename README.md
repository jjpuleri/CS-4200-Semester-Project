Project Overview:
------------------------------------
This project simulates and compares three cache replacement polices:
 - LRU (least recently used)
 - FIFO (first in first out)
 - Random (replacement)
Each policy is tested against 4 memory traces in order to evaluate hit rate, miss rate, and evictions

------------------------------------
File Descriptions:
------------------------------------
1. cache_replacement.py - this is the main simulation program
2. TestCasesFile.py - this is the example test cases for each policy
3. output_log.txt - this shows the sample output for the simulation
4. README.md - this is the project documentation
5. CS4200 Presentation part 1 & CS4200 Presentation part 1 - these show my presentation slides

------------------------------------
How to Run:
------------------------------------
This program requires Python 3.6 or higher. No external libraries are needed.
- run the main program (cache_replacement.py)
- run the test cases file (TestCasesFile.py)
- View the outputlog (output_log.txt)
